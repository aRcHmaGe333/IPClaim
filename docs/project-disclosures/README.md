# Project Disclosures

This directory contains concise public records of independent project ideas and systems.

Each disclosure captures the useful core of a project while leaving unresolved implementation, commercial, legal, and governance choices explicitly open for later work.

## Current disclosures

- [Accelerated](accelerated/README.md) — prospective projects are submitted to organisations with exceptional compute and execution capacity so the projects themselves can be rapidly advanced.
- [Conversation Visuals](conversation-visuals/README.md) — nearby spoken conversation drives relevant live imagery and other contextual visuals.
- [Source-to-Visual Video](source-to-visual-video/README.md) — chats, documents, project specs, README files, and similar source material are translated into a visual sequence that can be generated and assembled into video.

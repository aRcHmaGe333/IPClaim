# Conversation Visuals

## Core idea

A system listens to spoken audio in its environment, understands what is currently being discussed, and continuously displays images and other relevant visual material based on the live conversation.

The visual environment therefore changes with the conversation instead of remaining static.

## Example behaviour

A nearby conversation moves from architecture to a particular city, then to an artist, an unusual machine, a historical event, and an imagined future object.

The system can respond by surfacing or generating relevant visuals for each transition: photographs, diagrams, maps, artwork, animation, generated imagery, video fragments, data visualisations, archival material, or other useful visual forms.

The result is not simply subtitles on a wall. The surrounding displays become a visual extension of what people are talking about.

## Basic flow

1. Capture nearby speech.
2. Convert speech into usable language/context representation.
3. Track the current subject, entities, references, and conversational changes.
4. Decide which visual form would add the most value at that moment.
5. Retrieve, generate, or compose suitable visual material.
6. Present it on one or more displays.
7. Continue updating as the conversation changes.

## Possible environments

The same mechanism can work in:

- cultural and social venues;
- studios and collaborative workspaces;
- classrooms and workshops;
- exhibitions and installations;
- meetings and project rooms;
- homes;
- live events;
- public displays where the interaction model is appropriate.

## Relationship to Source-to-Visual Video

Conversation Visuals is live and reactive.

[Source-to-Visual Video](../source-to-visual-video/README.md) applies a related idea to a bounded source such as a chat log, document, project specification, or README and turns that source into a designed visual sequence that can become a video.

## Deployment considerations

Real-world implementations should make microphone use, consent, retention, and privacy controls visible and understandable to the people in the space.
